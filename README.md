# titanic-survival-prediction
ML PROJET : Prédiction de survie des passagers du Titanic

# Objectif du projet :
Analyser les données des passagers et construire un modèle 
de machine learning capable de prédire la probabilité de survie d'un passager

# Outils utilisés: 
- Python
- Pandas
- Matplotlib / Seaborn
- Scikit-learn

# Etapes de la réalisation du projet
- Chargement et nettoyage des données
- Analyse des données
- Sélections des variables pertinantes à la réalisation du projet
- Entrainement d'un modèle de classification
- Evaluation des performances et analyse des erreurs

# Résultats
Le modèle final atteint  75 % de précision sur les données du test.
